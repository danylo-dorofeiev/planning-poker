# Functional Requirements (FRs)

*Functional Requirement: ID → Epic → Description → Priority*

## Room Management

### 🟣 FR-001 Create Room 

> System shall allow a user to create a new collaboration room for planning poker sessions.
>
 >**Priority:** #High / Medium / Low
 
### 🟣 FR-002 Join Room

>System shall allow users to join an existing room using an invitation link or room identifier.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-003 Leave Room

>System shall allow users to leave a room they previously joined.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-004 Manage Room Participants

>System shall allow the room creator to view, add, and remove participants from the room.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-005 Delete Room

>System may allow users to delete a room, they previously created.
>
>**Priority:** #High / Medium / Low

## Task Management

### 🟣 FR-009 Create Task

>System shall allow users to create a task (ticket) within a session.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-010 Edit Task

>System shall allow users to edit a task (ticket) within a session.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-011 Delete Task

>System shall allow users to delete a task (ticket) within a session.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-012 View Task List

>System shall allow all session participants to view the list of tasks assigned to the session.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-013 Set Tasks Order

>System should allow users to change the order of tasks before/during a voting session.
>
>**Priority:** #High / Medium / Low

## Voting / Estimation

### 🟣 FR-014 Start Voting

>System shall allow start a voting round for all participants in the room.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-015 Reveal Votes

>System shall reveal all submitted votes once voting triggered by a session admin.  
>
>**Priority:** #High / Medium / Low

### 🟣 FR-016 Repeat Voting

>System shall reveal repeat the voting round for all participants in the room triggered by a session admin.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-017 Calculate Result

>System shall calculate and display aggregated estimation results for each task after votes are revealed.
>
>**Priority:** #High / Medium / Low

### 🟣 FR-018 Choose Deck

>System shall allow user admin to choose a voting deck for each of the tasks (tickets) in the room.
>
>**Priority:** #High / Medium / Low
