# UC-001 Create Room

*Use Case: ID → Title → Trigger → Main Flow → Alternative Flows → UC Diagram → Related FR*

## Related Requirements

- [FR-001](functional_requirements.md) 
  
##  Goal

Allow a user to create a room for collaborative planning poker estimation.

## Preconditions

- User is on the application home page.

## Trigger

User selects the option “Create Room”.

## Main Flow 
  
→ User clicks “Create Room”
→ System displays room creation form
→ User enters room details (name, optional settings)
→ User confirms creation
→ System validates input data
→ System creates a new room entity
→ System assigns the user as room owner
→ System redirects user to the newly created room page

## Alternative Flows

**A1: Invalid input data**

→ User submits empty or invalid room data
→ System rejects request
→ System displays validation errors
→ Room is not created

**A2: Unauthorized access**  

→ User is not authenticated
→ System blocks action
→ User is redirected to login page

## Postconditions
  
**Success:**  

- Room is created
- User becomes room owner (admin)
- Room becomes room identifier
- Room is available for other users to join
  
**Failure:**  

- No room is created
- System state remains unchanged
